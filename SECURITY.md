# Security policy

## Supported versions

Security fixes are provided for the latest published Faultora release.

## Reporting a vulnerability

Use the repository's **Security → Report a vulnerability** flow to create a
private GitHub security advisory. Do not include credentials, customer data, or
exploit details in a public issue.

Include the affected version, deployment mode, reproduction steps, impact, and
any proposed remediation. Reports will be acknowledged through the private
advisory thread.

The detailed threat model and security controls are documented in
[docs/SECURITY.md](docs/SECURITY.md).
