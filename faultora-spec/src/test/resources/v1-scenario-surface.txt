# The shape of a faultora.dev/v1 scenario document.
#
# Generated from the model and committed on purpose. ScenarioSurfaceTest fails
# when the two disagree, which is what makes the freeze a rule rather than a
# sentence in a document.
#
# From 1.0 the only change permitted in a 1.x release is an addition an older
# 1.x would have ignored rather than refused. A rename, a removal, a type
# change, or a field that becomes required is a new apiVersion. ADR-022.
